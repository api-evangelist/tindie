# Tindie

> Tindie is an online marketplace for indie and maker hardware — DIY electronics, kits, 3D-printing gear, robotics, and small-batch open-hardware products sold directly by independent creators. Tindie exposes a small public REST API (Django Tastypie) covering product listings and, for authenticated sellers, their orders and order line items.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's live API and public pages.

## APIs

- [Tindie API v1 index](https://www.tindie.com/api/v1/): Tastypie resource index (product, order, orderitem)
- [Product resource](https://www.tindie.com/api/v1/product/): Public product listings
- [Product schema](https://www.tindie.com/api/v1/product/schema/): Self-describing field schema (public)

## Authentication

- Tastypie ApiKeyAuthentication: `api_key` + `username` query params, or header `Authorization: ApiKey <username>:<api_key>`
- The `product` resource is public; `order` and `orderitem` require an API key (return 401 otherwise)
